# AccessBridge: Individual Portfolio

Equity-aware weekly outreach worklist for a diabetes outpatient clinic.
Applied Health Informatics, Capstone, Group 3. Participant: Shariffa Abdulhamid Garwan.

**All data are synthetic. No real patients. Not for clinical use.**
